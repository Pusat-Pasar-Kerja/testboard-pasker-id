# ADR 0002 - Asumsi teknis Milestone 0 & keputusan yang masih terbuka

- **Status:** Diterima sebagai default sementara (20 November 2026)

## Asumsi teknis yang diambil

| Topik               | Pilihan                                                                                                                               | Alasan                                                                                                                                                                                                                                                        |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Monorepo            | npm workspaces: `packages/shared`, `apps/api`, `apps/web`                                                                             | Sesuai doc 11; tanpa tool tambahan.                                                                                                                                                                                                                           |
| Versi tool          | TypeScript 5.9, Vite 7, Vitest 5, ESLint 10, React 19, Hono 4 + @hono/node-server 2, Zod 4, Tailwind 4, i18next 25 / react-i18next 16 | TS 5.9 & Vite 7 dipilih karena typescript-eslint belum mendukung TS 7 dan plugin Vite 8 belum semua menyusul. Vitest 5 & @hono/node-server 2 wajib karena versi lama punya advisory keamanan (tinypool critical, serveStatic); ESLint 9 sudah tidak didukung. |
| Paket shared        | Diekspor dengan kondisi `source` (TS langsung saat dev/test) dan `dist` saat runtime build                                            | Dev tidak perlu build shared lebih dulu; produksi tetap memakai JS hasil compile.                                                                                                                                                                             |
| API dev             | Same-origin: Vite mem-proxy `/api` ke `127.0.0.1:8787`                                                                                | Meniru reverse proxy Apache di produksi; cookie session nanti tetap same-site; tanpa CORS.                                                                                                                                                                    |
| Mode data web       | `VITE_DEMO_MODE` default `true` (mock)                                                                                                | Aman untuk prototype Cloudflare; tidak ada data/kredensial nyata.                                                                                                                                                                                             |
| API bind            | Produksi wajib loopback (`127.0.0.1`), divalidasi saat boot                                                                           | Security gate doc 09 #3.                                                                                                                                                                                                                                      |
| Pesan error backend | Bahasa Inggris generik; UI menerjemahkan berdasarkan `error.code`                                                                     | Kode stabil, terjemahan di frontend (doc 10).                                                                                                                                                                                                                 |
| Base path web       | `VITE_BASE_PATH` (default `/`)                                                                                                        | DEC-16 (subpath vs subdomain) belum diputus.                                                                                                                                                                                                                  |
